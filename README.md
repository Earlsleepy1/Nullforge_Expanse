## Project Summary

This repository adds:

- `nullforge:minecraft_bot`: combat bot with equipment, inventory, and drop logic.
- `nullforge:chat_bot`: interactable bot with keyword-based chat responses.
- Custom portal mechanics for `Nullforge Expanse` (early/after dragon) with dedicated functions.
- `bot_summoner` item to spawn bots directly.
- Voidforged armor recipes and reward systems.
- Setup and reset functions for easy in-world initialization.
